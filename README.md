# ARPA47: Passive Measurement of QUIC, ECH, and Post-Quantum Cryptography at the ISP Edge

[![Dataset DOI](https://img.shields.io/badge/Dataset_DOI-10.5281%2Fzenodo.22974122-blue?logo=zenodo)](https://doi.org/10.5281/zenodo.22974122)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)
[![Zeek Version](https://img.shields.io/badge/Zeek-v8.0.10%20LTS-orange)](https://zeek.org/)

> **Going Dark at the Edge:** A 30-Day Empirical Measurement of QUIC, Encrypted Client Hello, and Post-Quantum Cryptography Adoption at a South Asian Residential ISP.

This repository contains the measurement infrastructure, analytical scripts, and processing pipelines for an empirical network measurement study examining the co-adoption of TLS 1.3, Encrypted Client Hello (ECH), HTTP/3 (QUIC), and Post-Quantum Cryptography (PQC) at a live residential ISP edge in Chattogram, Bangladesh.

## Collection Architecture

The data pipeline operates on two distinct parallel layers:
<img width="6031" height="1045" alt="mermaid-ai-diagram-2026-09-26-132845" src="https://github.com/user-attachments/assets/f5db55dc-f056-462a-baf6-b77604139194" />

### Layer 1: Macroscopic (IPFIX / NetFlow)
- **Scope:** All 4,000 active residential subscribers
- **Tool:** MikroTik IPFIX export → `nfcapd` (nfdump toolchain)
- **Data:** Flow-level byte/packet counts, port distribution, session durations
- **Purpose:** Proves the volumetric shift from TCP/443 to UDP/443 (QUIC) across the full ISP

### Layer 2: Microscopic (TZSP + Zeek)
- **Scope:** A statically assigned `/24` PPPoE pool (225 active subscribers)
- **Tool:** MikroTik TZSP mangle → Linux virtual TAP → Zeek v8.0.10 LTS
- **Data:** TLS handshake metadata, QUIC SNI fields, DNS HTTPS RR queries, PQC key exchange
- **Purpose:** Deep protocol-level analysis of ECH, PQC, and QUIC header obfuscation

### Engineering Safeguards

Two MikroTik-specific issues required custom solutions:

1. **FastTrack Bypass:** RouterOS FastTrack optimization bypasses mangle rules for established connections, causing Zeek to see only one-sided traffic. Fixed by injecting two `accept` rules at positions 0 and 2 on the `forward` chain, above the FastTrack rules at positions 12–14.

2. **CPU Overload Watchdog:** TZSP encapsulation adds CPU load. A Python daemon polls the router CPU via the RouterOS API every 10 seconds. If load exceeds 85% for 10+ consecutive seconds, it automatically removes the TZSP mirror rules to protect subscriber QoS.

## Privacy & Ethical Compliance

All data collection adheres to the [Menlo Report](https://www.dhs.gov/sites/default/files/publications/CSD-MenloPrinciplesCORE-20120803_1.pdf) ethical principles for ICT research.

- **No payload capture:** Packet payloads were truncated at the interface level. Only connection metadata and cryptographic handshake headers were processed.
- **Cryptographic IP anonymization:** All subscriber IPs in the `10.60.1.0/24` pool were anonymized using a salted, **prefix-preserving CryptoPan HMAC-SHA256** algorithm. The cryptographic salt was destroyed after the collection window.
- **No MAC/PPPoE identifiers:** Layer-2 hardware identifiers were actively filtered and discarded.
- **Formal Ethics Certificate:** A signed Ethics Certificate is included in the Zenodo dataset: [`ETHICAL_COMPLIANCE_AND_DATA_SANITIZATION.pdf`](https://doi.org/10.5281/zenodo.22974122).

## Reproducing the Analysis

### Prerequisites

```bash
pip install -r requirements.txt
# pandas>=2.2, pyarrow>=16.0, duckdb>=1.1, numpy>=1.26
```

### Quick Start

1. Download and extract the dataset from Zenodo:
   ```
   https://doi.org/10.5281/zenodo.22974122
   ```

2. Extract the ZIP archives into a local directory:
   ```bash
   unzip conn.zip && unzip ssl.zip && unzip quic.zip && unzip dns.zip
   ```

3. Load QUIC sessions with Pandas:
   ```python
   import pyarrow.dataset as ds

   dataset = ds.dataset("quic/", format="parquet", partitioning="hive")
   df = dataset.to_table().to_pandas()
   hidden_sni = df[df['server_name'] == '-']
   print(f"QUIC sessions with hidden SNI: {len(hidden_sni):,}")
   ```

4. Analyze PQC adoption with DuckDB (no RAM required):
   ```python
   import duckdb

   result = duckdb.query("""
       SELECT date, COUNT(*) AS pqc_sessions
       FROM read_parquet('ssl/*/*.parquet')
       WHERE curve = 'X25519MLKEM768'
       GROUP BY date ORDER BY date
   """).df()
   print(result)
   ```

5. Verify dataset integrity against paper claims:
   ```bash
   python scripts/verify_integrity.py
   ```
